# GitHub发布步骤与作者确认事项

本文件夹是数据发布候选包，不是已经核验完毕的完整原始数据集。

1. 先处理KNOWN_ISSUES.md中的BBR比值、焓变、上下层标签、流变及模拟曲线来源问题。
2. 确认误差棒含义、重复次数、FTIR样品列对应关系和处理方法，以及PUMB旧样品名与PUPMA的对应关系。
3. 将缺失的关键原始数据和模拟输入/输出补入数据包；如无法补入，应准确描述公开范围及限制。
4. 数据许可按用户要求暂不指定。作者团队确认权利后选择许可，并同步更新README、CITATION.cff及仓库许可字段。
5. 在GitHub建立专用仓库，将本文件夹的内容上传至仓库根目录。审查尚未完成时建议先用私有仓库整理；不要把目录本身再嵌套一层。
6. 修订完成后在README中更新审查状态、文件范围、数据单位及真实仓库URL。不要直接声称“全部原始数据已公开”。
7. 发布一个明确的Release；需要DOI时，将同一版本存档到Zenodo并核对资源类型为Dataset。
8. 论文的数据可用性声明、数据集参考文献和GitHub/Zenodo版本应一致。未实际发布时不得写are publicly available。

不要只修改图表显示或论文数值来消除差异，应先根据原始记录判断错误所在。原始项目副本保持不变，可另建修正版并记录修正依据。
